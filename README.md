## What it does

`main.py` (stdlib-only Python) writes a single original warning label for a time machine — 102 characters — to `/output/entry.txt`:

> WARNING: Do not exit before your grandfather was born. He still needs a lift to meet your grandmother.

## Run

```sh
python3 main.py
```

The label is fixed and deterministic: the same text on every run.
